# FinanceBP · 财务经营分析桌面应用

**Windows 11 x64｜1.0 体验版｜安装后点击桌面图标使用**

从经营总览、预算差异到预测与月报，在一个独立窗口中完成财务分析。内置“星辰优选”模拟企业数据，安装后即可体验。

### [⬇ 下载 Windows 安装包 EXE · 约 297 MB](https://github.com/nixizoul0017/FinanceBP/releases/download/v1.0.0-rc.1/FinanceBP-1.0.0-windows-x64-setup.exe)

## 界面预览

![FinanceBP 经营驾驶舱功能界面](docs/assets/filter-apply.png)

界面支持**深海蓝、松石青、石墨紫**三种配色。月份、预算、分类与对象均先选择，再点击“应用筛选”统一生效；打开、搜索或关闭列表不会重新计算整个分析页面。

## 可以做什么

| 功能页面 | 主要用途 |
|---|---|
| 经营总览 | 查看净收入、成本、毛利、公司费用及经营利润 |
| 月度趋势 | 查看环比、同比和累计变化，拆解历史实际差异 |
| 维度分析 | 按商品、渠道、地区、部门、销售员等筛选或联合汇总 |
| 预算工作台 | 下载模板、校验导入、保存草稿、发布预算及调整版本 |
| 预算比较 | 定位销量、结构、均价、成本和退款带来的预算差异 |
| 预测与情景 | 历史回测、未来预测及情景假设比较 |
| 对账与跟进 | 核对来源和分析金额，保存月份确认及异常行动记录 |
| 点评与月报 | 生成带事实依据的点评及10张工作表的Excel月报 |
| 数据与下载 | 检查数据质量、字段映射，查看和导出分析明细 |

支持文件与 MySQL 读取、分类识别确认、自定义维度顺序、命名方案及本机记忆。已有数据库没有预算时，也可以在预算工作台编制本机预算；程序不会将这些预算写回企业 SQL。

## 安装后先体验模拟企业

保留左侧“数据来源”为 **完整模拟数据**，即可查看“星辰优选”的经营情况。也可以切换“多维模拟数据”“异名模拟数据”或“小样本核对”。

| 样本 | 主要内容 |
|---|---|
| 完整模拟数据 | 2024年1月至2026年9月，5万条原始订单明细，含退款、费用和2026年预算 |
| 多维模拟数据 | 部门、销售员、门店、客户类型，以及调岗、缺失归属和预算粒度差异 |
| 异名模拟数据 | 不同表名、字段名下的同一业务，验证通用映射 |
| 小样本核对 | 可逐笔计算的交易与跨月退款，便于学习和复核 |

**企业、客户、员工及交易均为人工构造的模拟内容，不含真实企业交易或客户隐私。** 所有样本、接入配置、SQL和生成脚本均随源码公开；安装包已内置体验所需样本。数据位置、字段、种子和核对方式见[模拟数据说明](docs/DEMO_DATA.md)。

## 数据、导出与使用边界

- 个人预算、对账、分类方案、偏好和预测版本保存在 `%LOCALAPPDATA%\FinanceBP`，升级及卸载默认保留。通过“文件”菜单备份、恢复、导入旧项目或打开数据目录。
- 导出使用系统“另存为”，上传使用系统文件选择窗口。Excel是当次已应用条件的快照；调整范围或假设后重新生成，精确原值另存JSON。
- 当前模板为人民币、不含税的商品销售。退款按发生月扣减；公司费用及经营利润保持公司口径，不自动按销售员等分摊。预算或历史不支持细分时明确显示不可比或不可用。
- 接入新企业仍需确认字段含义、数据粒度、日期和税口径。内置点评采用可追溯的事实模板；预测及模拟场景不代表真实企业的未来结果。
