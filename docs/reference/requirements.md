## 1. 五个管理问题

### Q01：本月收入和毛利相比上月、去年同月有什么变化？

你已提出需要看本月和上月销售额、成本。在此基础上补充去年同月、退款、毛利和毛利率，让收入变化能够连接到盈利变化。

| 项目 | 需求 |
|---|---|
| 指标 | 折后成交收入、退款额、净收入、净成本、毛利、毛利率、同比、环比、年度累计 |
| 数据来源 | orders、order_items、returns、dim_date |
| 关键字段 | 确认日期、订单状态、数量、原价、明细折扣、历史单位成本、退款日期/金额、成本转回 |
| 页面 | 经营总览：指标卡、月度趋势、对比表 |
| 用户操作 | 选择完整月份，查看与上月/上年同月的金额差异和变化率 |
| 验收 | 当月净收入−净成本=毛利；同比对应上年同月；缺少基期或基期<=0时有说明 |
| 对应阶段 | SQL阶段4，Python阶段6，网页阶段7 |

同一个商品的跨月退款可以影响退款当月；图表需遵循业务规则，不将退款日期替换为原销售日期。

### Q02：哪些商品、渠道、区域贡献最大的收入或毛利差异？

保留你提出的“按商品/渠道/区域计算收入、毛利、预算收入和预算毛利”，补充金额差异排序和明细追踪。

| 项目 | 需求 |
|---|---|
| 指标 | 各维度净收入、毛利、毛利率、预算值、差异额、正负向贡献金额 |
| 数据来源 | products、orders、order_items、returns、budget_sales |
| 关键字段 | 商品ID及分类、订单渠道/区域、确认与退款月份、销售与预算驱动字段、预算版本 |
| 页面 | 经营分析与预算分析：排名、对比柱状图、可追踪明细 |
| 用户操作 | 选择商品/渠道/区域维度，按收入、毛利或差异排序 |
| 验收 | 不重叠分组的合计等于所选范围总额；退款归属原订单维度；预算只使用一个版本 |
| 对应阶段 | SQL阶段4，网页阶段7，完整预算阶段8 |

若显示贡献比例，必须注明分母。正负差异抵消时，优先显示金额，负向贡献比例用各负差异绝对值之和作分母。公司共同费用不直接用于计算商品净利润。

### Q03：收入没完成预算，是销量、价格、结构还是退款差异？

| 项目 | 需求 |
|---|---|
| 指标 | 实际/预算净收入、金额差异、差异率、完成率、销量影响、结构影响、价格影响、退款影响 |
| 数据来源 | 月度实际销售汇总、退款汇总、budget_sales |
| 关键字段 | 月、商品、渠道、区域、成交销量、折后成交收入、预算数量/净单价、实际/预算退款金额 |
| 页面 | 驱动因素分析：瀑布图、因素贡献表、商品明细 |
| 用户操作 | 选择月份、预算版本和范围，查看预算到实际的差异组成 |
| 验收 | 四项影响之和等于净收入差异；折扣已进入价格，不能重复拆一次；零预算不计算完成率 |
| 对应阶段 | 阶段8 |

固定商品集合与统一单位先完成标准PVM；新增/停销商品和零销量基期应单列说明。展示数字因素后，给出需要进一步调查的业务问题，不将数学分解视为因果证明。

### Q04：当前业绩下，全年收入和经营利润预计是多少？

| 项目 | 需求 |
|---|---|
| 指标 | 累计实际、剩余月份收入/毛利/费用预测、全年收入/经营利润预测、全年预算差额 |
| 数据来源 | 历史实际与费用、年度预算、forecast_runs、forecast_sales、forecast_expenses |
| 关键字段 | 历史月份、销量、净单价、单位成本、退款和成本转回、费用分类、截止月、假设、预测版本 |
| 页面 | 滚动预测：实际与预测趋势、全年对比、假设与回测误差 |
| 用户操作 | 查看或生成预测版本，检查未来销量、价格、成本与费用假设 |
| 验收 | 全年预测=截止月累计实际+剩余月份预测；已知实际不被覆盖；回测无未来数据泄漏 |
| 对应阶段 | 阶段9 |

预测方法从上年同月和近期均值基准开始，业务驱动方案经过回测后再选择；不预先保证某个准确率。

### Q05：调整价格、销量、采购成本和营销费用，结果怎样变化？

| 项目 | 需求 |
|---|---|
| 输入 | 相对基础预测的价格、销量、单位成本、退款率、营销费用变化；输入范围需校验 |
| 指标 | 情景收入、毛利、毛利率、公司经营利润，与基础预测的差额 |
| 数据来源 | 阶段9基础预测、情景假设和公司费用预测 |
| 页面 | 情景模拟：输入控件、基础/乐观/谨慎对比、假设表 |
| 用户操作 | 调整一个或多个参数，查看未来及全年结果；重置到基础情景 |
| 验收 | 零调整返回基础预测；价格和销量按乘法计算；销量不能为负；费用变化只计一次 |
| 对应阶段 | 阶段9 |

第一版情景作用于剩余月份，不重算已经发生的实际。价格+5%、销量−3%的成交收入变化为+1.85%，并非+2%。销量变化是用户假设，不自动推断需求弹性。

## 3. 通用页面规则

- 显示筛选期间、币种、金额单位、实际截止月、预算/预测版本和口径入口。
- 图表、指标、明细和下载使用同一筛选条件。
- 空数据、零预算、缺失预算和无历史基期分别提示，不统一显示为0。
- 商品、渠道、区域可组合筛选收入与毛利；公司经营利润始终明确公司范围。
- 毛利率变化使用百分点；增长率、差异率和完成率的名称与分母清楚。
- 报告标明模拟数据；主要数字能追踪至汇总与原始明细。

## 4. 数据质量与报告要求

1. 重复ID、非法日期、未知引用、负数量、超额折扣、超额退款进入异常记录。
2. 同一文件成功导入后再次导入，不重复增加有效记录和金额。
3. 销售、退款、费用和预算按各自粒度处理，再汇总组合，避免一对多连接放大金额。
4. 记录模拟数据参数与预设业务变化，方便检验分析结果。
5. Excel月报至少含总览、实际与预算、维度明细、PVM、预测假设、点评和口径说明。
6. AI只处理已计算指标；主要数字先核对，失败时可使用模板继续输出报告。
