# 五分钟演示稿（讲解提纲）

这是个人模拟电商项目“星辰优选”，数据覆盖2024-01至2026-09，目标是把SQL数据、财务口径、经营分析和预测连成一个可运行、可复核的流程。它是本地运行的Python网页应用，默认文件模式即可演示。

**0:00—0:40：问题与数据。** 管理者想知道为什么收入增长而利润下降、预算偏差来自哪里、未来假设变化会产生什么结果。展示README、模拟数据标注和七页看板。说明订单、退款、费用、预算的粒度不同，必须先分别处理。

**0:40—1:30：口径。** 打开经营总览，展示2026-09净收入267,927.12、毛利102,104.16、公司费用60,504.74、经营利润41,599.42。讲公式：净收入=确认销售收入−按发生月确认的退款；净成本=销售历史成本−退款可冲回成本；毛利=净收入−净成本；经营利润=公司毛利−公司费用。商品筛选仅改变销售/毛利，公司费用仍为公司范围。

**1:30—2:25：预算差异。** 打开预算比较：本月净收入比预算少24,921.20元，毛利少32,929.45元。讲PVM按总销量、结构、均价、退款依次分解；指出均价-26,709.55元是金额贡献，需要进一步调查促销、渠道结构和定价，不能直接当作因果结论。点进商品P020，再回到总桥说明不能重复相加。

**2:25—3:25：增长但毛利下降。** 对比2025-09与2026-09：净收入多10,038.14元，净成本多27,203.16元，毛利少17,165.02元。打开月度趋势和维度分析，演示如何把管理问题落实到可核对的商品/渠道/区域明细。说明跨月退款与历史单位成本会影响归期和解释。

**3:25—4:20：预测与情景。** 展示三种方法的历史回测和截至9月的预测：基础全年净收入3,372,229.39元，公司经营利润677,525.66元。改变未来价格或单位成本，观察新情景；明确历史实际不被改写，模型预测是对未来的假设测算。

**4:20—5:00：报告与交付。** 打开点评与月报，生成10表Excel和精确JSON。任选一句点评，指出事实ID、指标来源及明细；修改假设后重新导出，旧Excel保留原快照。展示使用指南：项目包在新目录和新Python环境已复现；实体新电脑操作需由使用者完成。

面试常见追问：①为什么退款按退款月？因为本模型按事件确认月记录，并保留原销售维度；②为什么商品筛选不分摊公司费用？没有可信分摊规则，不制造商品利润；③缺成本、预算和空月份如何处理？展示“不可用/未知”，已加载且确认为零才显示0；④预测是否真的准确？展示历史回测及局限，不称为已实现的真实预测准确率；⑤换一家企业能直接用吗？当前是电商模板和字段映射接入，业务语义变化需要适配和校验。
