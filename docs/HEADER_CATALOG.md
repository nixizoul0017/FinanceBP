# 按表头勾选分类（1.2.0）

默认导入流程为：**选择文件或连接数据库 → 确认表头 → 勾选分类并改名 → 确认导入**。全部表头都会显示，不再要求先对应商品、渠道、地区，日期、金额、数量、编号等也可以作为分类候选。

## Excel及其他文件

1. “数据来源”选择“自定义配置”，接入方式选择“上传业务数据（Excel / DTA 等）”。
2. 选择文件；每个工作表单独显示，可以取消不需要的表。
3. 在“第几行作为表头 / 分类名称”中选择行号，默认第1行。若前面有标题或说明，例如第2行才是姓名、城市、部门，请选择2。JSON、DTA使用自身字段名，无须选行。
4. 下方会列出全部表头。在“启用”列勾选需要的分类，在“分类名称”列直接改名。例如原表头“任职地”可以显示为“城市”；原始文件和原始列名不变。
5. 勾选确认后，点击“确认分类并导入”。未确认的改动不替换当前数据。表头为空、重复、启用名称为空或重复时，会提示修正。

文件格式和大小限制沿用[文件导入说明](FILE_IMPORT.md)。勾选分类并不改变字段原值；空分类单独列为“未归属”，汇总不丢记录。同一文件中的不同表独立查看，不自动合并或复制金额。

## MySQL数据库

1. “自定义接入方式”选择“连接数据库并识别表头”。
2. 填写连接信息，点击“连接并列出数据表”。
3. 选择需要的表，点击“读取所选表并识别表头”。数据库直接使用列名，不选择第几行。
4. 在同样的表头清单中勾选、改名，再确认导入。

读取采用只读一致性快照，不创建或修改源表；编辑分类不重新查询数据库。密码仅用于当次连接，不保存到接入配置。重新打开保存的数据库接入时，需要输入密码重新读取；同一次使用中只改名称、勾选分类，可复用已有快照。

## 确认后的查看与修改

导入后可选择数据表，看到记录数、全部表头数和已启用分类数。按选择顺序联合分组，筛选具体对象后点击“应用分类”，结果与CSV下载统一更新。三个筛选常驻，已启用的额外分类集中在“更多分类”中。普通表的汇总指标明确为**记录数**，不把每一行称为订单，也不把任意数值列当成收入。

左侧“分类与映射”可重新选择表头行、勾选、停用及改名。修改原字段的显示名称不改变其稳定编号；文件新增或删除表头时要求重新确认，不自动替换为其他列。停用后不继续应用隐藏的筛选；原条件失效时请核对后重新应用。

分类配置按企业与接入名称保存至本机，重新打开可以复用。原业务文件复制、个人数据目录及备份边界见[文件导入说明](FILE_IMPORT.md)。

## 可选的财务分析

**分类名称与财务计算含义分别设置。** 普通名册、业务清单等文件即使没有订单号、金额或日期，也能先完成分类导入及记录汇总。需要计算收入、成本、预算和预测时，在文件接入中打开“同时设置财务分析（可选）”，再确认实际字段与完整月份。

商品、渠道、地区不会强制成为额外分类；财务引擎保留必要的内部字段以维护原口径，界面只使用你启用的分类。金额或日期被选作分类，不会改变金额计算或日期确认。新勾选字段也不会自动成为预测的训练粒度；细分预测仍需在高级设置中明确配置。

原有财务数据源的“分类与映射”同样列出全部表头，可直接勾选和改名。独立员工表等关联、预算版本粒度、细分预测放在“高级：关联、预算及细分预测设置”；关联必须通过唯一键和金额不放大校验。销售部门和费用部门不自动合并。已有MySQL财务接入配置继续兼容，新企业完整财务接入仍须确认其业务口径。

1.2.1进一步合并财务导入的编号选择，并识别带时分秒及中文冒号的支付时间，见[文件导入说明](FILE_IMPORT.md)。

1.2.2对已识别的订单表推荐少量经营分类及财务设置，用户仍可取消、增加分类或改名，所有表头候选保留。没有数量列可默认1，单日文件走部分期间分析，见[文件导入说明](FILE_IMPORT.md)。
