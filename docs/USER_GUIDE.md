## Windows 独立安装版

当前1.2.2 Windows 11 x64 安装包，双击 `FinanceBP-1.2.2-windows-x64-setup.exe` 安装后，从桌面或开始菜单打开 FinanceBP。无需安装 Python、Excel，不必使用 START 或输入网址。关闭窗口会停止它自己的后台进程。运行环境已内置，安装时缺 WebView2 使用随包离线组件。旧用户先关闭应用，可备份个人数据后运行新版安装器更新。

“文件”菜单可以备份、恢复、导入旧项目及打开个人数据目录；“帮助”提供重新加载、诊断日志和关于。个人数据位于 `%LOCALAPPDATA%\FinanceBP`，源码模式仍使用项目 outputs。导出采用系统“另存为”，文件上传使用系统选择窗口，取消不会替换原文件。恢复与导入前会自动备份，保留旧来源文件；备份不包含企业来源数据、MySQL库、密码或日志。

安装包与主程序未代码签名，当前验收状态见 [Windows 验收清单](WINDOWS_ACCEPTANCE.md)。详细运行与迁移说明见 [Windows 应用指南](WINDOWS_APP.md)。Mac 本轮保留源码入口，不提供应用安装包。

## 导入自己的Excel或Stata文件（1.1.0）

**1.2.0表头分类：**默认先选表头行（第1行）、列出全部表头、勾选和改名，再确认导入；数据库也可直接连接、选表并按列名启用分类。普通分类导入不再强制填写财务映射，之后可在“分类与映射”修改。详见[按表头勾选分类](HEADER_CATALOG.md)。

**1.2.1导入修正：**财务设置默认只需“订单编号（唯一明细编号）”一个选择；同一订单多行时再打开高级选项，指定独立明细编号。支付时间、付款时间支持日期加时分秒，包括`2026-10-21 9：20`；分析取其中的日期，仍须确认该列代表销售确认日。详见[业务文件导入说明](FILE_IMPORT.md)。

**1.2.2首次订单导入：**上传后识别订单、日期与金额，自动推荐财务设置和所属月份；成交数量没有列时保留默认1。单日流水保留“部分期间”选项，确认后查看“文件内已知交易分析”，在顶部选分析分组并应用即可分类核对金额。完整月指标和预测不使用单日数据，缺成本不补0。推荐设置和分类仍可修改，详见[导入步骤](FILE_IMPORT.md)。

**1.1.1修复提示：**等待选择文件、填写映射或确认期间时不应一直显示“加载中”。1.1.0存在遮罩残留问题，请更新1.1.1后重新打开。

左侧“数据来源”选择 **自定义配置 → 上传业务数据（Excel / DTA 等）**，选择文件后确认工作表、字段、分类及完整实际月份，点击 **验证并应用业务数据**。支持 `.xlsx`、`.xls`、`.xlsm`、`.dta`、`.csv`、`.tsv` 和记录列表JSON，可多选文件；原来的接入配置JSON移至“已有JSON配置（高级）”。

本页下载的1.2.2包含业务文件导入及后续修正；历史1.0体验版不包含这些更新。详细字段、金额精度、缺失数据和保存规则见[业务文件导入说明](FILE_IMPORT.md)。文件格式可不同，但仍需核对日期、销售确认及财务口径。本版沿用未签名体验版和[待验收边界](WINDOWS_ACCEPTANCE.md)。

## 源码模式（开发与学习）

普通用户使用上面的EXE即可。完整环境要求另见[源码运行说明](SOURCE_RUN.md)。

### 双击打开，无需输入

0.1.2起，Windows双击根目录 **START.cmd**；Mac双击 **START.command**。程序显示准备进度，自动检查环境、补全依赖、启动网页服务，确认可用后打开默认浏览器。**不再输入1，也不需要自己开启服务或输入网址。** 旧0.1.1包仍使用菜单且只允许Python3.14，请完整解压新版包，不要只替换一个启动文件。

0.1.3修复Windows PowerShell5.1将Python检测命令中的引号处理掉而误报“未找到Python”的问题。若使用0.1.2出现该提示，先替换为新版，不要仅凭旧提示重装Python。

两个系统均需完整64位Python3.13或3.14，包含pip、venv及Tk图形组件，首次安装需要可用的Python包源。Windows需要PowerShell5.1或以上；Mac使用与Intel或Apple Silicon芯片匹配的解释器、系统终端和Bash。实体Mac与最低macOS版本尚未实测；Windows Python3.13/3.14的实际验证见项目日志。

保持启动窗口运行。正常结束时点击“关闭程序”，它会停止本窗口启动的服务；关闭浏览器标签不停止服务。再次查看可以点击窗口的“打开网页”。电脑重启后重新双击入口。

一般地址为http://127.0.0.1:8501。已有经核对的同项目服务运行时复用现有页面；其他程序占用时自动选择附近空闲端口，打开对应地址。不要只刷新原来的旧端口，也不要双击app.py寻找界面。

## 随时切换界面颜色

左侧按经营分析、预算与预测、报告与数据分组，点击带图标的名称即可切换，当前页面整行高亮。主区域显示“加载中”时请等待当前计算结束；提示消失后即为新页面。总览右上角“查看月报”可直接进入月报页。

月份、预算版本与显示单位集中在白色筛选栏。顶部分类1—3可更换维度，每位下方选择具体对象，留空表示全部；“更多分类”中可增加位置。配置过第四位维度后，即使对象留空也默认展开。具体操作见[动态分类指南](reference/dynamic_dimensions.md)。完整模拟数据默认万元，小样本默认元。经营利润始终为公司全口径，共同费用未分摊，不随销售筛选变化。

**0.5.1统一应用筛选**：月份、预算版本、显示单位、分类和对象都可连续修改。底部出现“有未应用的修改”时，下方指标、图表、当前范围、下载与月报仍保持原条件；点击“应用筛选”后一次性更新。没有有效变化时按钮禁用。打开、搜索、关闭列表与编辑只更新筛选区，不会触发全屏加载。

“取消修改”恢复最后已应用条件。切换左侧页面也会自动放弃待选修改；需要带到下一页的条件请先应用。“维度分析”的“分析分组”位于同一顶部区域，与范围分别选择、一起应用。选命名方案先填入待选内容；应用后才记忆，保存/更新前必须先应用。只记分类、顺序、分组和方案身份，对象、月份及密码不长期保存。

刷新来源若发现原分类、对象、月份或预算版本失效，会暂停分析并提示重新应用。请核对待选区，选择正确对象或明确接受全部后应用；程序不会直接扩大原分析范围。发布本机预算是独立的确认操作，成功后会选中刚发布的版本。预测仍需要完整实际月；切页不会自动改掉已应用的月份。

点击左侧顶部“外观配色”按钮，选择深海蓝、松石青或石墨紫。全部页面共用同一选择，侧栏、卡片、按钮与趋势/预算/预测图表一起变化。配色不会清空筛选、修改数据或重新生成Excel，已经生成的月报快照继续保留。

0.5.0新增“预算工作台”和“对账与跟进”。数据库没有预算时，可下载模板后导入、保存草稿并确认发布；对账录入独立依据后可保存月份确认；月度趋势可直接用历史实际解释变化。异常支持负责人、原因、证据、行动、期限与复盘，详见[财务工作流程](reference/finance_workflow.md)。新两个页面将原销售筛选收进展开区，保留当次选择，但预算编制和公司对账不受销售筛选影响。

Windows应用在 `%LOCALAPPDATA%\FinanceBP\runtime`、源码模式在 `outputs/runtime/ui_preferences.json` 记录本机最后一次选择，刷新浏览器、关闭后再次打开均可恢复。项目目录无法写入时，提示“本次生效，暂无法记住选择”；损坏或未知的偏好会回到默认深海蓝。新电脑解压的项目不包含旧偏好，首次默认深海蓝。

## 出错时看弹窗

弹窗会显示出错阶段、原因、处理方式和日志路径。安装/服务日志在outputs/runtime；窗口提供“查看错误日志”按钮。请保留提示，以便后续定位。

| 出错阶段 | 常见处理 |
|---|---|
| Python环境 | 安装完整64位Python3.13或3.14，再双击；不自动安装系统Python |
| 启动窗口/Tk | 使用包含Tk的Python安装；`python3 -m tkinter`可检查Mac图形组件 |
| 项目文件 | 完整解压整个ZIP，保留目录结构 |
| 本机环境/版本 | 不复制其他电脑的.venv；把不适用的旧.venv移到项目外，再启动 |
| 创建环境/安装组件 | 确认目录可写、Python带venv和pip |
| 依赖安装/加载 | 检查网络、包源、芯片架构和日志；缺依赖时程序会尝试自动补全 |
| 网页服务 | 查看启动日志、端口、运行环境和本机网络保护提示 |
| 浏览器 | 设置系统默认浏览器后点击“打开网页”；此时服务可能已经正常运行 |

## Mac入口权限与自定义Python

ZIP记录了START.command的执行权限。若GitHub源码下载解压后没有执行权限，在项目目录的终端执行一次：

```bash
chmod +x START.command
```

也可用 `bash START.command` 自动启动，不需要输入数字。自定义Python位置时：

```bash
FINANCEBP_PYTHON="/你的Python安装路径/python3.13" bash START.command
```

路径需替换。入口按指定解释器、本机.venv、python3.13、python3.14、python3寻找，并核对版本和64位。缺Tk会由系统弹窗提示；标准图形组件说明见[Python官方文档](https://docs.python.org/3.13/library/tkinter.html)。

Windows可通过本机FINANCEBP_PYTHON环境变量指定安装路径；普通安装会通过现有.venv、注册表和Python启动器查找，不要求人工执行安装命令。

## 换电脑与数据库

数据库连接表单采用浅底深色文字。点击主机、数据库、用户名、密码或端口后，边框会高亮，显示浏览器原生文字光标；Tab可切换到下一项。密码默认遮蔽，可用眼睛按钮临时查看。[表单聚焦示例](assets/mysql-input-focus.jpg)。

携带完整项目ZIP，在新电脑完整解压，用本系统入口启动，不复制.venv。默认文件模拟数据无需MySQL/Navicat/Excel或AI账号。远程MySQL需要网络可达、连接参数和账号权限，本机不必安装MySQL服务。

原电脑本地数据库不会随ZIP迁移，要另行备份恢复或连接服务器。127.0.0.1表示当前电脑。参考configs里的MySQL示例创建企业配置，本地配置命名为`*.local.json`；密码读取时输入或由本机环境提供，不写进JSON。首次接入确认字段、粒度、币种、税口径、日期、退款和成本，见[架构](reference/architecture.md)。

## 维护菜单与开发入口（可选）

日常只双击入口。需要安装、验收、打包和学习脚本时，使用[维护指南](DEVELOPMENT.md)中的管理入口：

```powershell
# Windows项目目录
.\.venv\Scripts\python.exe scripts/manage.py
.\.venv\Scripts\python.exe scripts/manage.py --action Verify
.\.venv\Scripts\python.exe scripts/manage.py --action Package
```

```bash
# Mac项目目录；带参数时进入维护操作
bash START.command --action Verify
bash START.command --action Package
.venv/bin/python scripts/manage.py
```

文件验收包含两来源等价、33个月恒等式、SQL样本基准、完整月报和10表Excel共17组。Windows的run_stage系列保留供学习与开发。实体Mac、另一台实体电脑和真实企业适配仍须实际完成后记录。
