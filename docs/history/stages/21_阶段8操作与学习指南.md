# 阶段8：预算差异与经营驱动因素

> 阶段原始档案：保留当时的任务、决定和验证记录。当前使用方法见[使用指南](../../USER_GUIDE.md)，持续更新见[项目日志](../../PROJECT_LOG.md)。文中的阶段输出路径属于历史记录。


本阶段回答“实际比预算差多少，这个差额由哪些金额因素组成”。预算比较页已增加维度贡献排序、收入桥、毛利桥、公司利润桥、因素明细与精确下载。继续使用阶段7的看板入口，无需重新建库或导入数据。


程序须持续运行，单独收藏网址不能在重启电脑后自动启动后台。默认完整模拟文件不需要MySQL密码。窗口窄时先展开左侧菜单；看完整图表可以把浏览器窗口放宽。

先选择2026年9月、B2026_V1、全部商品/渠道/区域。更换预算版本只使用新版本，不会把多个版本相加。三个图表标签分别是“净收入差异桥”“毛利差异桥”“公司经营利润差异桥”。

## 2. 按这个顺序练习

1. 查看上方实际/预算表，确认月份、版本、范围与差额。
2. 在“定位差异的维度”依次选择商品、渠道、区域，找出较大的不利贡献。
3. 查看净收入差异桥，按销量、结构、均价、退款理解金额贡献。
4. 点击因素上方的深色圆点，观察下方因素选择框与商品明细；也可以直接使用选择框。
5. 查看毛利桥，定位单位成本及成本转回；再看公司利润桥中的费用差异。
6. 下载因素CSV、商品输入和分析JSON，用原始金额复核；阅读自动生成的调查案例。

瀑布图从预算出发，加上各项贡献，走到实际。正贡献把指标向上推，负贡献把指标向下拉。图中“新成交”表示预算该商品销量为0、本期有成交；“未成交”表示预算有销量、本期没有成交，不能由此认定企业新上架或永久停销。

贡献排序与因素拆解是两种看法。商品差异合计可以解释公司差异；价格/销量等因素合计也解释同一个差异。不能把商品差额再次加到因素桥里。

## 4. PVM为什么要这样算

P、V、M分别表示价格、销量、商品结构。计算对象是退款前的折后销售，折扣已经含在均价中，不再加一项折扣差异。

先对“预算与实际都有正销量”的共同商品集合计算。设预算总销量Q0、实际总销量Q1，商品预算占比s0、实际占比s1，单价p0、p1：

```text
总销量影响 = (Q1−Q0) × 预算加权平均单价
商品结构影响 = Q1 × Σ((s1−s0) × p0)
均价影响 = Σ(q1 × (p1−p0))
净收入差异 = 上述三项 + 预算无销量商品的本期收入
             − 预算有销量但本期未成交商品的预算收入
             − (实际退款−预算退款)
```

顺序固定为总销量→结构→均价，交互项分配到后面的因素。改变顺序，各项贡献可能变化，总差额仍应一致。本期或预算没有销量的商品单列，不编造缺失单价，不强行算占比。

小例子：A预算10件×100元、实际12件×90元；B预算10件×200元、实际8件×200元。预算3000元，实际退款前2680元。总件数均20，销量影响0；低价A占比提高，结构影响−200；A降均价贡献−120。若实际退款80、预算退款0，净收入差额是−400元。

页面按商品汇总后计算平均售价，已经按月×商品×渠道×区域核对预算覆盖。因此均价变化可能含折扣、渠道与区域成交占比变化，不能直接断言是标价下降。商品结构贡献则表示共同商品之间件数占比的变化。

## 5. 毛利与利润为什么分开

```text
共同商品销量影响 = Σ((q1−q0) × (p0−c0))
均价影响 = Σ(q1 × (p1−p0))
单位成本影响 = −Σ(q1 × (c1−c0))
退款影响 = −(实际退款−预算退款)
成本转回影响 = 实际转回−预算转回
```

再加上预算无销量商品的本期成交毛利、减去预算有销量但本期未成交商品的预算成交毛利，就能连接预算毛利与实际毛利。此模型的商品销量变化已经包含结构，不能再加入收入桥的结构金额。

公司利润桥再加入“−公司费用差异”。费用实际400、预算380，费用差额+20，对利润的贡献是−20。销售筛选不改变公司利润桥；共同费用没有分摊到商品。

## 6. 怎样理解贡献占比与精度

假设两个商品分别贡献−100和+80元，总差额−20元。不能说前者正常占总差额500%而不解释抵消。页面的不利贡献占比以所有负贡献绝对值之和为分母；正贡献占比显示0，没有不利贡献或存在未知差额时占比为空。费用则以超预算额为不利金额。

原始事实金额仍使用Decimal。平均价涉及除法，可能是无限循环小数；分解内部采用有理数检查恒等式，输出为60位精度Decimal。JSON的`reconciled`说明数学模型是否勾稽，`representation_residual`记录有限小数表示尾差。

页面金额四舍五入至分，分项合计有时会相差1分。因素汇总表另列“显示舍入尾差（非经营因素）”，使展示金额也能核对。它不改变业务贡献、原始事实或CSV原值。图表只是展示副本；精确核对以分析JSON和CSV为准。

缺预算维度不能当作预算0，不能自动归入新成交贡献。未提供退款来源时退款前PVM仍可计算，净收入桥未知；缺成本时收入桥可用、毛利/利润桥未知；缺费用只阻止公司利润桥。当前件数口径未确认时不强行做PVM。

## 7. 不打开网页也能生成结果

在项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_stage8.ps1'
```

默认分析完整模拟数据2026年9月，保存`outputs/stage8/variance_result.json`、因素CSV和`预算差异调查案例.md`。JSON包括企业、规则、来源内容指纹、月份、筛选和预算版本；公司费用与利润明确保留独立范围。CSV金额单位为元，未知值为空字段，文本有公式保护。

小样本运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_stage8.ps1' -Profile 'configs/sample_files.json'
```

更换月份使用`-Month '2026-08'`；范围可用`-Products P005 -Channels C03`。每次入口会更新默认结果和调查案例；因素CSV文件名包含范围、预算版本与快照，页面下载也遵循这些标记。

调查案例给出数字事实与待核实建议。促销、供货、流量或采购变化仍需业务记录支持。本阶段没有接入AI服务，不会把推测写成已证实经营原因。
