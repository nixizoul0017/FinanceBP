# 阶段11：整体验收与迁移指南

> 阶段原始档案：保留当时的任务、决定和验证记录。当前使用方法见[使用指南](../../USER_GUIDE.md)，持续更新见[项目日志](../../PROJECT_LOG.md)。文中的阶段输出路径属于历史记录。


本项目是Python运行、浏览器操作的本地财务分析应用。默认读取个人模拟文件；连接MySQL时分析过程只读。Excel为当次快照，在网页调整后重新导出。本指南验证技术重建，同时保留用户亲自操作和另一台实体电脑的确认步骤。

## 1. 新电脑需要带什么

使用outputs/stage11/release/FinanceBP_Stage11.zip，解压得到FinanceBP文件夹。包内包含程序、启动脚本、锁定依赖、两套模拟文件和小样本、配置模板、SQL、测试、必要核对基准、说明及展示截图；不会复制旧.venv、数据库密码、开发日志和QA运行时目录链接。

最低运行准备：Windows、Python3.14、PowerShell和浏览器。当前实测Python3.14.7。建议64位Python，依赖中的数据处理库需要对应平台支持；其他系统或Python版本未作为本次通过结论。首次依赖安装需要包源或已准备的离线依赖，本项目包不包含Python安装器和离线依赖包。

解压后在FinanceBP目录打开PowerShell，依次执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\setup_python.ps1'
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_stage11.ps1'
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_stage7.ps1'
```

如果环境创建脚本找不到Python，用-PythonPath指定自己电脑上的python.exe，不使用开发电脑路径。第一条重新创建.venv并安装requirements.txt；第二条执行文件模式整体验收；第三条启动七页看板。

浏览器访问http://127.0.0.1:8501。保持启动窗口运行，结束时按Ctrl+C。端口已被占用可在第三条追加-Port 8502，并访问相应地址。127.0.0.1表示当前电脑，网址本身不能携带程序。

## 3. 连接新的数据库

默认文件演示不要求MySQL或Navicat。连接远程MySQL只需要网络可达、对应账号权限和连接配置；本地数据库迁移则另做数据库备份和恢复，项目包不含旧电脑数据库服务器的数据文件。

以configs/demo_mysql.example.json为参考建立企业配置，确认地址、端口、库名、表字段映射、币种、含税口径和完整历史期间。在网页上传配置并输入本次连接密码。不要把密码写进JSON或项目包。不同企业接入必须核对业务含义，不只是改字段名。

首次接入先抽取小样本，核对原表与标准数据的订单数、金额及退款归期，再启用分析。当前业务模板是人民币不含税商品销售；其他行业、币种和数据库类型需要增加适配与验收。

完整回归：


重建演示小样本可使用run_stage3.ps1和run_stage4.ps1；请先阅读10指南，参数明确指定自己的MySQL客户端位置及专用演示库。本项目不要求在企业业务库执行演示建表脚本。

开发验收用validate_stage11_mysql.ps1创建独立临时MySQL实例，执行样本建表/视图、完整导入、重复与回滚、财务SQL、PVM、预测和月报核对。它需要本机MySQL服务器程序，-MySqlDirectory须指向自己的安装目录，默认临时端口33324。临时实例无密码，仅用于本地验收，完成后关闭并清理；它不是实际业务部署方案。

## 5. 你亲自完成的最后操作

1. 在另一台Windows电脑解压项目，重新安装依赖并执行文件验收。
2. 在经营总览核对四项本月金额。
3. 选择单个商品，确认商品收入/毛利变化，公司费用与公司利润保持公司范围。
4. 在预算比较解释收入桥和毛利桥，说明金额贡献不等于业务原因。
5. 在预测与情景调整未来假设，确认历史实际不变。
6. 在点评与月报生成报告，追踪一条点评至事实ID和明细；修改假设后重新导出。
7. 按29经营案例和30演示稿独立讲解，记录自己仍需解释的部分。

本次代理验收使用同一台电脑的独立目录和新.venv；另一台实体电脑及你能否独立讲清不由自动检查替代。里程碑C须在上述操作确认后勾选。
