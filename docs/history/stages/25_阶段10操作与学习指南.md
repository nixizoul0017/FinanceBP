# 阶段10：经营点评与Excel月报

> 阶段原始档案：保留当时的任务、决定和验证记录。当前使用方法见[使用指南](../../USER_GUIDE.md)，持续更新见[项目日志](../../PROJECT_LOG.md)。文中的阶段输出路径属于历史记录。


阶段10已完成固定模板点评和10张工作表的Excel月报。你确认采用“网页调整假设，导出的Excel保存当次分析快照”的方式。原计划中的openpyxl负责导出，网页与报告继续调用同一套财务模块。

## 1. 先操作一次

打开[本地经营看板](http://127.0.0.1:8501/)，左侧选择“点评与月报”。默认选择完整模拟数据、2026-09、B2026_V1、销售范围全部。预测方法自动、近期窗口3、选型指标公司净收入、自定义调整全部0，然后点击“生成点评与Excel月报”。

第一次计算会包含历史回测，请等生成成功提示。随后页面展示本月指标、经营点评和三个下载按钮：

1. Excel经营月报：用于审阅、筛选、整理和分享。
2. Markdown经营点评：适合阅读及编辑文字。
3. 精确JSON分析包：保存原金额、计算结果、点评引用和版本，用于复核。

月报预测设置在本页独立选择。如果与“预测与情景”页核对，需保持月份、筛选、预算、方法、窗口、选型指标和自定义调整一致。切换月份或销售范围后，旧报告会隐藏；重新点击生成取得对应结果。表单内参数需点击生成才提交。

Excel是本次结果快照，在Excel里修改一个数字不会重新运行Python模型或同步网页。调整经营假设时回到网页重新生成并下载，保留旧报告用于比较。

## 2. 月报包含什么

| 工作表 | 阅读重点 |
|---|---|
| 总览点评 | 本月收入、毛利、公司费用与利润；趋势、预算、因素、维度和预测点评 |
| 实际预算 | 当月实际/预算/差异/比率，公司费用单独比较；年初至当前实际；预算组合明细 |
| 维度分析 | 商品、渠道、区域收入毛利，预算差异及负向贡献比例 |
| 驱动因素 | 收入、毛利、公司利润桥的状态、金额因素及商品/费用明细 |
| 预测结果 | 四套情景的累计实际、剩余预测、全年预测与预算；月度实际/预测、未来销售和公司费用 |
| 预测假设 | 四套参数、历史MAE/WAPE/偏差、模型设置和数量规则 |
| 销售明细 | 本月确认销售、当时成本快照、商品渠道区域和完整性 |
| 退款明细 | 本月确认退款及原销售日期，保留跨月事件 |
| 公司费用 | 公司全口径费用原始明细及费用预算比较 |
| 口径与追溯 | 数据属性、期间、预算、报告/预测版本、来源与训练指纹、点评事实清单 |

金额和比率保存为数值，日期保存为日期，可以排序、筛选和继续分析。金额显示至分，负数用括号，已确认0按财务格式显示短横线；“不可用”表示缺失或不适用，不能当0参与计算。

Excel通常只能保留约15位有效数字；本报告为数值展示快照，高精度Decimal原值保存在配套JSON。复制显示至分的因素金额求和可能有分位舍入差异，完整勾稽应核对JSON和驱动桥的表示尾差。

## 3. 点评如何得到

输入是同一来源、同一月份和筛选下的实际分析包、预算驱动包和预测包。程序从已计算值中提取事实，记录F001等身份及结果包路径，用固定句式生成文字，再检查引用与来源是否一致。

例如默认9月结果：

- 当前净收入267,927.12元，毛利102,104.16元。
- 公司费用60,504.74元，经营利润41,599.42元。
- 净收入预算292,848.32元，实际减预算−24,921.20元。
- 均价因素贡献−26,709.55元，总销量因素贡献−11,980.83元。这是负向因素，其他正向贡献会抵消一部分，不代表两项之和就是全部净差异。
- 商品P020、渠道C02和区域R01分别在各自维度中贡献最大的收入负差异。不同维度是同一批业务的不同切法，不能把三个维度的差额再相加。
- 基础情景全年净收入3,372,229.39元、公司经营利润677,525.66元，属于模型测算。

没有完整数据时，程序保留可用事实，并提示成本、退款、费用、预算或历史缺失。例如缺成本仍可展示已确认净收入，但毛利与经营利润不可用，不会补成0。

## 4. 学会区分四类文字

| 类别 | 示例 | 能说明什么 |
|---|---|---|
| 事实 | 本月收入、实际减预算、环比金额 | 当前数据与已计算比较 |
| 金额分解 | 均价因素贡献多少 | 数学桥接中金额如何组成 |
| 模型测算 | 某情景全年预计收入/利润 | 给定历史与假设下的结果 |
| 待验证建议 | 核实活动、供货、定价与合同 | 下一步需要什么业务证据 |

“均价因素为负”不能直接证明降价导致预算未完成。当前均价包含折扣与成交组合变化；确认原因需要活动、订单、渠道和供应记录。模拟数据的预设变化也不会自动被写成已证实的企业原因。

报告保留公司费用与利润的全公司范围。筛选P005后，销售与毛利、销售明细和销售预测跟随筛选，公司费用、费用预算和公司利润仍保留整体。

## 5. 版本与复核

报告身份以R10开头，根据来源、月份、范围、预测假设及结果内容生成。相同输入得到相同报告身份，Excel文件本身的保存时间和压缩元数据可能不同，不能靠文件字节是否相同判断计算结果是否相同。

配套JSON包含原始标准明细、实际/预算/驱动/预测结果和每句点评的引用。预测内容身份以FC9开头，设置一致时与阶段9相同。报告导出不会自动创建阶段9的不可覆盖版本；若需要冻结预测，可在“预测与情景”页保存。

复核顺序：点评文字→事实ID→结果包路径→对应汇总/明细。程序在导出前检查事实原值和来源、文字、企业、规则、来源指纹、期间、范围及预测设置。一旦核对失败就停止导出，避免继续显示旧报告。

## 6. 本地脚本

网页继续使用阶段7启动入口，已包含阶段10。脚本导出在项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_stage10.ps1'
```

输出在outputs/stage10：含R10版本的Excel、commentary.md、report_result.json和export_manifest.json。后两个便捷文件保存最近一次脚本结果；含版本的Excel用于区分内容。

自定义价格+5%、销量−3%：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\scripts\run_stage10.ps1' -QuantityChange -0.03 -PriceChange 0.05
```

还可使用-Products P005、-Method last_year_same_month、-Window 1、-Objective operating_profit，以及单位成本、退款、成本转回、营销和全部费用参数。页面5表示5%，脚本0.05表示5%。

本机已安装openpyxl3.1.5及et-xmlfile2.0.0，并加入requirements.txt。依赖用途见[openpyxl项目说明](https://pypi.org/project/openpyxl/)。新电脑按阶段11重建环境，不复制旧.venv。

## 7. 大模型在这里的位置

当前采用本地固定模板，没有接入外部AI接口，不需要密钥，也没有外部调用费用。第一版的结果输出已经可独立运行。

以后若明确接入大模型，可以让它根据结构化事实改写文字；仍需核对数字、期间和范围，并保留模板作为失败时的结果。当前没有实现或验收外部模型的调用与故障处理，也不把固定模板称为AI生成。

## 8. 你的学习顺序

1. 按默认设置生成月报，核对总览的净收入、毛利和公司经营利润与其他页面一致。
2. 找到“净收入实际减预算”一句，去实际预算表验证减法；再查看驱动因素，不把负向因素之和误当总差异。
3. 查看退款明细，找一条销售月早于退款月的记录，说明为什么影响退款确认月。
4. 筛选P005重新生成，解释销售范围变化与公司费用不变。
5. 自定义价格5%、销量−3%，重新导出，解释为何本月实际不变而未来测算变化。
6. 选择一句点评，找到它的事实ID、原值及依据；区分事实、金额分解、模型测算与建议。
7. 用自己的话讲完整流程：SQL/文件取数→校验与标准化→财务计算→驱动与预测→点评→月报。
