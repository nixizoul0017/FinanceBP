# 第一阶段操作指南

> 阶段原始档案：保留当时的任务、决定和验证记录。当前使用方法见[使用指南](../../USER_GUIDE.md)，持续更新见[项目日志](../../PROJECT_LOG.md)。文中的阶段输出路径属于历史记录。


本阶段先把业务与计算规则说清楚。完成后进入数据库设计，再开始SQL。

当前06、07文档已共同起草并保存，不需要你从空白填写。下面的步骤保留为阅读与练习指引；文档与代码由我们在对话中逐项完善。

## 步骤1：写一段业务说明

使用以下默认背景起步，可根据兴趣调整：

> 星辰优选是一家自营销售家居生活用品的电商企业，通过3个渠道向4个区域销售20种商品。财务BP每月需要分析收入、毛利和费用，解释预算偏差，并预测全年结果。所有经营数据为模拟数据。

用自己的话写下：谁使用系统？需要做什么决策？为什么仅有收入数字还不够？

产出：`docs/reference/business_rules.md`的“业务背景”部分。

## 步骤2：选择5个管理问题

从以下问题开始，在每个问题后写出你想查看哪些数字：

1. 本月收入和毛利相比上月、去年同月有什么变化？
2. 哪些商品、渠道、区域贡献最大的收入或毛利差异？
3. 收入没完成预算，是销量、价格、结构还是退款差异？
4. 当前业绩下，全年收入和经营利润预计是多少？
5. 如果调整价格、销量、采购成本和营销费用，结果怎样变化？

产出：`docs/reference/requirements.md`，每个问题对应所需指标、字段和展示结果。

## 步骤3：确认7条规则

阅读`03_财务指标与模型口径.md`，在业务规则中写下：

1. 完成订单按确认日期计入销售。
2. 取消和未确认订单不计收入。
3. 折扣是整条明细金额，不重复乘数量。
4. 退款按退款确认月份减收入。
5. 成本使用成交快照，退货按实际可转回成本处理。
6. 公司费用只计入一次，共同费用先留在公司级。
7. 利润显示为本项目管理口径经营利润。

遇到不理解的规则先用例子说明，先解决再建表。

## 步骤4：自己算一笔交易

样本：卖出5件商品，原价120元/件，明细折扣50元，单位成本70元。随后在同月退回1件，退款110元，成本转回70元。

分别计算折后成交收入、净收入、净销售成本、毛利和毛利率。再回答：如果退款发生在下月，两个自然月的数字分别是什么？

先自己计算，再核对：折后成交收入550元；同月净收入440元；净成本280元；毛利160元；毛利率36.36%。如果下月退款，本月收入550元、成本350元、毛利200元；下月收入−110元、成本−70元、毛利−40元。

另增加一条取消订单和一条无退货补偿，验证你能区分收入和成本的变化。

产出：`data/sample/手算样本.csv`或业务规则中的样本表。记录原始数字、确认月份、退款月份与期待结果。

## 步骤5：检查是否可以进入下一阶段

- 能区分订单和订单明细。
- 能解释一笔退款为什么可能影响下个月。
- 能算清收入、成本、毛利及其关系。
- 能列出5个管理问题所需的数据。
- 业务规则和样本结果已保存。

满足这些条件后，更新执行清单，进入阶段2，完成商品、订单、订单明细与退款的关系设计。
