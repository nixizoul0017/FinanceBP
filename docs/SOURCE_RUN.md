# 源码运行说明（开发与学习）

普通 Windows 用户请从[项目首页](../README.md)下载 EXE 安装包，安装后点击桌面图标。本页仅供需要运行源码、学习 SQL/Python 或继续开发的人使用。Mac 暂无应用安装包。


以下仅针对源码ZIP，Windows独立安装版不需要这些准备。完整解压整个源码项目后，按电脑系统选择入口，使用浏览器查看；两个源码入口使用同一份代码和数据。

| 项目 | Windows | Mac（macOS） |
|---|---|---|
| 日常入口 | 根目录 `START.cmd` | 根目录 `START.command` |
| Python | 完整64位Python **3.13或3.14**，包含pip、venv和Tk图形组件 | 完整64位Python **3.13或3.14**，包含pip、venv和Tk；使用与Intel或Apple Silicon芯片相匹配的解释器 |
| 启动环境 | Windows PowerShell 5.1或以上，已设置默认浏览器 | 系统终端与Bash，已设置默认浏览器 |
| 首次安装 | 能访问Python包源，依赖自动安装 | 能访问Python包源，依赖自动安装；当前锁定依赖仍需在实体Mac验证 |
| 查看界面 | 本机浏览器 | 本机浏览器 |
| 验证状态 | 本机启动与财务验收通过 | 已提供专用入口，**尚未在实体Mac验收**，未声明最低macOS版本 |

源码ZIP不含Python安装器、运行环境或离线依赖；Windows应用安装包则内置运行环境。默认模拟文件模式无需MySQL、Navicat、Excel或AI账号。接入企业MySQL时另需可访问的数据库、账号及字段配置；本地数据库要另行迁移。

### Windows 源码：双击 START.cmd

1. 安装完整64位Python3.13或3.14，完整解压项目。
2. 双击根目录 **START.cmd**，无需输入任何内容。
3. 进度窗口自动检查/准备环境、补全依赖，确认服务就绪后直接打开默认浏览器。
4. 保持启动窗口运行。下次使用仍双击同一个入口。

### Mac：双击即可使用

1. 安装与芯片架构相匹配的完整Python3.13或3.14，完整解压项目。已有3.13不必仅为本项目升级。
2. 双击根目录 **START.command**，无需输入数字或网址。
3. 首次使用自动创建本机.venv并安装依赖，启动窗口显示进度；服务就绪后直接打开默认浏览器。
4. 以后仍双击同一个入口。若缺Tk，弹窗会提示安装完整Python；可用 `python3 -m tkinter` 检查图形组件。[Python官方说明](https://docs.python.org/3.13/library/tkinter.html)。

若从GitHub下载后提示没有执行权限，在终端先进入解压的项目文件夹，然后执行一次：

```bash
chmod +x START.command
```

也可以直接在项目文件夹中执行 `bash START.command`，仍会自动启动。若提示找不到Python，确认已安装3.13或3.14；自定义安装位置的处理见[使用指南](USER_GUIDE.md)。请完整解压当前源码包，不要混用旧版本的启动文件。

### 两个系统的使用方式

网址通常为 `http://127.0.0.1:8501`；端口占用时选择附近空闲端口，以启动窗口打印为准。保持“完整模拟数据”即可体验。

**只需双击本系统启动入口，无需自己另开网页服务。** 保持启动窗口运行，结束时点击“关闭程序”；关闭浏览器标签不会停止服务。已有经核对的同项目实例运行时直接打开现有页面；其他程序占用端口时选择空闲端口，自动打开正确网址。换电脑只带项目ZIP并重建环境，不复制.venv。

### 出错时如何处理

环境问题不会只留下一页“连接错误”。启动失败会弹窗列出**出错阶段、原因、处理方式和日志路径**，区分Python版本、缺项目文件、环境创建、安装组件、依赖安装/加载、网页服务和默认浏览器问题。窗口提供“查看错误日志”与“打开网页”按钮。日志在outputs/runtime，不进入发布包。

缺少Python时，入口用系统弹窗提示；缺Tk时同样提示具体组件。网络安装失败请按弹窗检查包源和网络，修复后再次双击入口。安装期间可等待进度完成，不用手动复制网址。
